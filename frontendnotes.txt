Flow:

Frontend (AuthRegLog.jsx)
        ↓
POST /users/login
        ↓
Backend validates email + password
        ↓
Backend generates JWT token
        ↓
Backend sends token
        ↓
Frontend stores token
        ↓
Frontend sends token in future requests
        ↓
Backend verifies token

Frontend just attaches token. Backend checks token.

Login validation → Backend
Token generation → Backend
Store token → Frontend
Attach token → Frontend
Verify token → Backend
